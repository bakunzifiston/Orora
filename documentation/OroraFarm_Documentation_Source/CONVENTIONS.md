# Writing conventions (all manuals)
- Source is GitHub-flavoured Markdown, one file per chapter, named NN-title.md (NN = order). Each starts with a single `# Chapter title` (H1 = chapter; numbering added automatically by the build). Use `##`/`###` for sections.
- Tables: standard pipe tables. Callouts: blockquote starting with `> **Note:**`, `> **Warning:**`, `> **Tip:**`, or `> **Example:**`.
- Diagrams: fenced ```mermaid blocks (flowchart / sequenceDiagram / erDiagram / stateDiagram-v2). Keep them under ~25 nodes, short labels. Add a caption line italic below.
- Screenshots: `![Caption text](../screenshots/<name>.png)`; the lead will capture them from the running app. For every screenshot you reference, append one line to `<manual-dir>/shots-wanted.txt` as `name|/url-path-to-open|what must be visible (e.g. click "Add animal")`. Use lowercase-hyphen names prefixed by manual (eu-, ad-). Only reference screens that really exist (verify route + view).
- Truth rule: document ONLY what the code does. Verify every field name, validation rule, permission and workflow in controllers / FormRequests / services / models / migrations / blade views. If something is partial, stubbed or absent, say so under a "Known limitations" note. Never describe planned features as existing. Use the exact UI labels from the Blade views (and lang/en.json).
- Do NOT modify any application code, migrations or config. Write only inside documentation/OroraFarm_Documentation_Source/.
- Never include real user emails/names from the database; use the demo workspace (demo@ororafarm.rw, "Orora Demo Farm") or invented examples.
- App basics: Laravel app at /Users/cepsa/Desktop/Orora; routes in routes/web.php, routes/modules.php, routes/marketplace.php; module nav in config/modules.php; permissions config/workspace_access.php; multi-tenancy via tenant_id column (see MULTITENANCY.md, app/Services/TenantContext.php, app/Models/Concerns/BelongsToTenant.php). Platform admin lives under /admin (guard auth:admin); farm workspace users use the normal session.
