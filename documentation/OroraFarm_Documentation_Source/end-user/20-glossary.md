# Glossary

Words used on OroraFarm screens and in this guide, in alphabetical order.

| Term | Meaning |
|---|---|
| Abattoir | A slaughterhouse. In Sales you can dispatch healthy animals to an abattoir and record the meat that comes back |
| Accounts receivable | Money customers still owe you for completed sales. Shown as "Receivable" in Finance |
| Active | A status meaning "in use". An active animal can be sold or milked. An active customer or employee is current |
| Alert | A reminder on the Dashboard (for example "Vaccinations due"). It is worked out each time and disappears when the problem is fixed |
| Animal | One individual animal (for example a cow with a tag number) |
| Attachment | A file added to a record, such as a photo of a receipt (PDF, JPG, PNG, DOC, DOCX, up to 5 MB on expenses) |
| Audit trail | A list on customer and employee pages that shows who changed what and when |
| Balance due | Sale total minus payments received. What the customer still owes on that sale |
| Base salary | The agreed pay of an employee (before any deduction), in RWF |
| Blacklisted | A customer status for a buyer you no longer want to sell to |
| Bulk tank / Chiller / Can / Bucket | Types of milk storage container |
| Calf | A young animal. For milk feeding: under 12 months, or in the "Calves Group" |
| Cancelled | A status for a milk session or sale that was stopped. Cannot be re-opened |
| Capacity | The most litres a storage tank can hold |
| Category (distribution) | The use of milk: Sold, Fed to calf, Household, Neighbor, Relative or visitor, Other |
| Category (expense) | The type of an expense, such as Feed purchase or Labor |
| Collection (Finance) | The Finance entry made when a customer payment is received |
| Completed | Final status of a milk session or a sale. It can no longer be edited |
| Confirm & deduct stock | The button on a milk sale. It takes litres from the tank and completes the sale |
| Contact | A person you can call at a customer (customer contacts) |
| Credit limit | The amount a customer is allowed to owe. A warning only: it does not block sales |
| CSV | A simple spreadsheet file (comma separated values) used to import or export lists |
| Customer | A person or organisation that buys from you |
| Customer code | An automatic code like CUS-0001 |
| Dashboard | The first page after sign-in with summaries, charts and alerts |
| Default address | The main address of a customer or employee |
| Destination tank | The tank that receives the milk when a session is completed |
| Discount | Money taken off a sale total |
| Display name | The name shown in lists |
| Distribution (milk) | A record of what happened to milk that was not sold (calves, household, neighbours and so on) |
| Draft | A record still being prepared. A draft sale is not final and is not counted in revenue or Finance |
| Dry (lactation stage) | A cow that is not producing milk at the moment |
| Emergency contact | Someone to call if an employee has an emergency |
| Employee | A record of a person working on the farm. It is not a login |
| Employee code | An automatic code like EMP-0001 |
| Expense | Money spent on the farm |
| Farm | A physical farm site. Most records belong to a farm |
| Finance entry | An automatic accounting record made when a sale is completed, a payment is received or an expense is paid. Also called a ledger entry or transaction |
| Flock | A group of birds (poultry) managed together |
| Herd / Livestock group | A group of animals managed together, for example "Cows (lactating)" |
| Inactive | A status for something no longer used, but kept for history |
| Inquiry | A message from a buyer about one of your Marketplace listings |
| Intake | Milk that enters a tank from a completed milking session |
| Lactating | A cow that is giving milk. Only lactating cows can be milked in a session |
| Lactation number | How many times the cow has calved and given milk (1, 2, 3 ...) |
| Lactation stage | Early, Mid, Late or Dry |
| Ledger | The list of all Finance entries |
| Listing | An advertisement in the Marketplace |
| Livestock | The group record that holds animals. See "Herd" |
| Marketplace | The public site where buyers see listings |
| Milk record | The litres from one cow in one session |
| Milk session | One milking time (morning, afternoon or evening) for one herd on one date |
| Milking method | Manual, Machine or Semi-automated |
| Mobile money | Payment by phone (for example MTN or Airtel money) |
| Movement (milk storage) | A change in a tank's quantity: Intake, Sale, Distribution, Distribution reversed |
| Net income | Revenue minus expenses |
| Notification | A message in the bell and Notifications page |
| On leave | An employee status for someone away for a period |
| Open (session) | A milk session where you can still add or remove cow records |
| Outstanding balance | The total a customer owes on sales that are not draft or cancelled |
| P&L | Profit and loss: income, expenses and net income for a period |
| Paid (expense) | An expense that has been paid. Only Paid expenses are counted in Finance and cost per litre |
| Paid (payment status) | A sale paid in full |
| Partial | A sale with some payment but a balance still due |
| Pay frequency | How often an employee is paid: Monthly, Weekly, Bi-weekly or Daily |
| Payment method | Cash, Mobile money, Bank transfer, Cheque or Other |
| Payment reference | A code that identifies a payment, such as a mobile money transaction number |
| Payment terms | Agreed time to pay, for example "Pay in 14 days" |
| Payroll | The pay agreement stored for an employee. OroraFarm does not calculate or pay salaries |
| Period | A date range used by reports (Today, This month, This year ...) |
| Permission | A right given by the workspace admin: view, create, edit or delete in a module |
| Pregnancy check | A test to confirm if an animal is pregnant after breeding |
| Primary | The main contact, address, farm or assignment among several |
| Producing animals | Active animals with production status Lactating (used in cost per litre) |
| Production status | An animal's state such as Lactating |
| Recognition (Finance) | The Finance entry made when a sale is completed or an expense is paid |
| Revenue | Income from completed sales |
| Reversal | An opposite Finance entry that cancels an earlier one |
| RWF | Rwandan franc, the currency used in OroraFarm |
| Sale | A selling transaction. Types: Animal sale, Meat sale, Milk sale, Egg sale |
| Sale number | An automatic code such as MLS-20261102-0001 (milk), SL- (animal), MET- (meat), EGS- (egg) |
| Session code | An automatic code like MS-20261102-0001 |
| Shift | The time of milking: Morning, Afternoon or Evening |
| Sold | An animal status after an animal sale is completed. Also the milk distribution category created by a milk sale |
| Source | Where a record came from, for example an expense created from a Health record |
| Status | The stage a record is in (Open, Completed, Paid, Draft ...) |
| Storage container | A tank, can or bucket where milk is kept |
| System category | A built-in expense category that cannot be deleted |
| Tag number | The unique number or name on an animal's ear tag |
| Tax | An amount added to a sale total |
| Tenant / Workspace | Your organisation's private area in OroraFarm. You only see your own data |
| Terminated | An employee status for someone who has left |
| Trace | A public page where a buyer types an animal's tag number to see its history |
| Transferred | An animal status, for example after being sent to an abattoir |
| Trust level | A customer rating: New, Regular, Trusted or VIP |
| Udder condition | Normal, Inflamed or Mastitis suspected |
| Unaccounted milk | Milk produced minus milk with a recorded use, in the Milk overview |
| Unpaid | A sale with no payment yet |
| Vendor | A shop or person you buy from or pay |
| Void | An expense status meaning cancelled |
| What's new | The page with release notes from the OroraFarm team |
| Workspace admin | The user who manages other users and their permissions |
| Yield | The litres of milk produced |
